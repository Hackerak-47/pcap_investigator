What Network Captures Establish

Analysis relies strictly on observable wire signals:

  • Cleartext protocols (HTTP, DNS, Telnet) exposing commands or URLs
  • Negotiated TLS protocol version in plaintext ServerHello responses
  • Cipher suite agreed upon between client and server
  • Destination port activity (e.g., port 80 cleartext vs port 443 encrypted)

Investigation Boundaries

To preserve accuracy, this system acknowledges analysis limits:

  • Encrypted HTTPS payloads cannot and will not be decrypted or read
  • Traffic on port 443 without handshake metadata cannot be assumed to be TLS
  • Missing handshake metadata indicates uncaptured initial packets, not insecurity
  • Zero-day detection cannot be claimed merely from protocol absence
