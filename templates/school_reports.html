AES-256-GCM

CONFIDENTIALITY

Galois/Counter Mode provides authenticated symmetric encryption. It protects report contents from unauthorized viewing while providing tamper detection (integrity + authenticity) via an authentication tag.

SHA-256 Hashing

INTEGRITY

A deterministic one-way cryptographic hash generates a unique 256-bit digest of both the raw PCAP file and final report artifacts. Any alteration in even a single bit completely changes the hash value.

RSA-PSS Signatures

AUTHENTICITY

Probabilistic Signature Scheme (PSS) with RSA-2048/SHA-256 provides digital signing. The report digest is signed with a private key; recipients verify authenticity with the public key without exposing the signer.
