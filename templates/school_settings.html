Cryptographic Setup Reference

DEVELOPER UTILITY

To enable AES-256-GCM encryption and RSA digital signatures, generate keys and add them to your .env file:

1. GENERATE 32-BYTE AES KEY: 
python -c "import os,base64; print(base64.b64encode(os.urandom(32)).decode())"
2. GENERATE RSA-2048 KEYPAIR FOR SIGNING: 
openssl genrsa -out signing_key.pem 2048
openssl rsa -in signing_key.pem -pubout -out signing_key_pub.pem
3. GENERATE ADMIN PASSWORD HASH: 
python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('your-secure-password'))"
